App Description:
MODULE 3: Medicine Scanner & AI Verification
Purpose

This is the heart of the application.

What This Module Does

Users can:

Scan medicine packaging.
Upload medicine photos.
Extract medicine information using OCR.
Detect:
Medicine Name
Expiry Date
Batch Number
Manufacturer
Verify medicine authenticity.
Compare packaging with reference patterns.
Generate risk scores.
AI Functions

AI:

Reads package text.
Detects expiry dates.
Identifies suspicious patterns.
Calculates confidence scores.
Generates risk assessment.
Why It Exists

Many citizens cannot determine whether a medicine is:

Genuine
Suspicious
Expired
Potentially counterfeit

This module provides an initial verification layer.
